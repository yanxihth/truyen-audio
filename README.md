# Truyện Audio

Trang nghe truyện audio từ Archive.org, chạy trực tiếp bằng cách mở `index.html` trong trình duyệt.

Menu **Powered by Trung Hiếu** gồm tốc độ phát, hẹn giờ tắt, tua đến phút và tùy chỉnh ID truyện, ảnh nền, ảnh bìa. Có thể dùng link ảnh hoặc chọn ảnh từ máy.

Cài đặt, ảnh đã chọn và tiến trình nghe được lưu trong trình duyệt trên máy đang sử dụng.

## Xuất bản lên GitHub Pages

Đưa mã nguồn lên một kho GitHub, sau đó mở **Settings → Pages**, chọn **Deploy from a branch**, nhánh **main** và thư mục **/ (root)**.

Trang không cần bước build. Tệp `.nojekyll` cho phép GitHub Pages phục vụ trực tiếp HTML, CSS và JavaScript hiện có.

Mỗi trình duyệt lưu cài đặt riêng. Khi truy cập địa chỉ web mới lần đầu, trang dùng ảnh và ID truyện mặc định trong `index.html`.
